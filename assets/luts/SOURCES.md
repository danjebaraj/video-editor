# LUT sources

All bundled `.cube` LUTs are generated by `scripts/gen_luts.py` from simple, documented color math (S-curves, white-balance shifts, saturation and a teal/orange split-tone). They are original works released under CC0 with this repository; no third-party LUTs are included.

| File | Look |
|---|---|
| warm_film.cube | gentle S-curve, warm balance, lifted blacks, −10 % saturation |
| cool_clean.cube | light S-curve, cool balance, +5 % saturation |
| punchy.cube | strong S-curve, +30 % saturation |
| bw_contrast.cube | luminance-only, strong S-curve |
| teal_orange.cube | teal shadows, orange highlights, +10 % saturation |
