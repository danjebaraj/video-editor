## M0 — Foundation
Built:
- Cargo workspace with all 12 crates from §3.1, `xtask` (`cargo xtask ci`), GitHub Actions (macOS-14, windows-latest allowed to fail, ubuntu), `deny.toml`.
- `cutline-deps`: platform dirs (`CUTLINE_HOME`), tool discovery (env → tools dir → PATH), version parsing (`-/filter_complex` vs `-filter_complex_script`), capability probing, downloads with sha256 + retry, zip/tar extraction, lockfile, stage/promote/rollback.
- CLI: `doctor` (+ `--json`), `deps install ffmpeg|whisper-model|face-model|--all`, `deps update [--check]`, `deps rollback`, `deps status`, `probe [--loudness]`, `selftest --quick` (M0 checks). JSON output conventions and exit codes 0–4.
- `cutline-media`: ffprobe normalization (fps, VFR, rotation, color, alpha incl. VP9 `alpha_mode`, faststart detection), fingerprints, cache helpers.
- `cutline-testkit`: frame-ID video generator/decoder, tone/noise/burst audio, alpha overlays (ProRes 4444, VP9 alpha, PNG sequence), grid and beep/flash sources, FFT, RMS, SSIM, golden compare (`CUTLINE_BLESS=1`).
- Bundled OFL fonts in `assets/fonts/`.

Acceptance:
- `deps install ffmpeg` installs a working ffmpeg and records it in the lockfile. Verified for real on Linux with Martin Riedl 9.0.2, plus a mock-server integration test (`crates/cutline-cli/tests/m0_cli.rs`). The macOS run is covered by CI (**not run here**).
- `doctor --json` lists capabilities (test).
- `probe` on ProRes 4444 / VP9 alpha / PNG sequence fixtures (test).
- Frame-ID round trip through x264 CRF 23 + scale to 1080×1920, 300/300 frames (test).

Deviations: see `docs/decisions.md` (ffmpeg sources, Linux support).

## M1 — Project model & basic render

NTSC), targets and safe zones, timeline resolution (transitions overlap math, anchors, speed/ramps, freeze extension), semantic validation (30+ codes).
- `schema/project.schema.json` generated by schemars, plus a test that it is current.
- `cutline-media`: probe all project assets (cached by fingerprint) → `MediaLookup`.
- `cutline-render`: segment builder (frame-exact seek, speed, reverse, VFR→CFR, rotation via autorotate, SAR, BT.709 conversion, `cover`/`fit_pad`/`fit_blur`), content-addressed segment cache (asset fingerprint + filter + deps + geometry + versions), ProRes 422 HQ / PCM f32 mezzanines, concat + xfade assembly, dialogue join with sample-exact acrossfade, libx264/AAC final encode per target profile, `-/filter_complex` vs `-filter_complex_script` by ffmpeg version, `--dry-run` printing every command and script, draft geometry (540p) with optional HW encoder.
- `cutline-qa`: first QA checks (container/codec/faststart, geometry/fps/CFR, color tags, duration, Shorts limit, A/V alignment, bitrate) and delivery side files.
- CLI: `validate`, `schema`, `init [--target] [--assets]`, `expand` (explicit project + EDL), `render [--export] [--draft] [--dry-run] [--no-cache] [--allow-qa-errors] [--hw] [--jobs]`, `preview --at …|--range a-b [--safe-zones]`, `qa`.
- `selftest --quick` now renders a Shorts project and checks frame mapping, per-clip tones and QA.

Acceptance:

- Invalid-project suite: 33 cases with code + JSON path (`crates/cutline-core/tests/invalid_projects.rs`).

- Windows path escaping: unit tests (drive letters, specials) plus a real ffmpeg test with spaces, commas, quotes, brackets and `ü` in the path.

## M2 — Audio pipeline
Built:
- `cutline-audio`: voice chains (`clean_voice`, `podcast_warm`, `raw`; `arnndn` only with a verified model path), energy VAD, ducking envelope, loudnorm JSON parsing/pass filters, f32 WAV writer and decoder, `audio.png` renderer (per-role waveforms, final mix, duck envelope, momentary LUFS with target line; built-in bitmap font).
- Render audio stage: role stems from dialogue (sample-exact joins), audio/VO/music layers (trim, loop, gain, fades, sample-precise placement), SFX layers (asset or brand alias, deterministic `pick_from`), clip audio replacement, transition SFX at the transition midpoint, video/B-roll layer audio. Ducking by envelope (`amultiply`) or `sidechaincompress`; speech from transcripts or VAD. Mix, then two-pass loudnorm with a measured correction pass. Dry-run shows the stems, mix and both loudness passes.
- QA: loudness (±1 LU, TP), LRA (warn), clipping (sample count ≥ −0.1 dBFS), digital silence > 1.5 s, black frames, freeze, first frame, Shorts hook, caption safe zone and reading speed (boxes come from M4/M5). Intended spans (transitions, freeze effects, stills) are excluded. An analysis pass that fails is now a QA error, never a silent pass.
- Selftest Shorts project now has a ducked music bed and loudness QA.

Acceptance (`crates/cutline-render/tests/m2_audio.rs`):
- Final mix within ±0.5 LU at −14 and −16 LUFS targets; true peak ≤ target.
- Ducking: music (200 Hz Goertzel) is lower by `amount_db` ±1.5 dB during speech; attack/release half-depth crossings within ±50 ms of the model.
- No sample-step discontinuities above the tone's legitimate slope at a hard cut or an audio-cut transition.
- Tone per segment via FFT with wipe and fade transitions present.
- `audio.png` renders at 1568 px width.

## M3 — Motion, transitions, overlays, color
Built:
- All 52 xfade transitions, plus custom `whip_left/right/up/down` (slide + directional avgblur), `zoom_punch` (zoomin + flash), `flash_cut` (white or colored), `glitch` (pixelize + rgbashift + seeded noise), and `cut`. Audio crossfades or hard cuts with micro-fades (M2).
- Effects: punch-in (with optional hold + release), zoom, Ken Burns (scale + pan), shake (impact headroom + decaying offsets), flash (white via `eq`, colored via `drawbox`), blur-in (gblur sigma ramp via sendcmd), glitch, vignette, motion blur (tmix). Easing: linear, quad/cubic/expo × in/out/in_out, back, spring, with Rust and ffmpeg-expression versions kept in sync.
- Speed ramps (closed-form setpts), freeze frames (`loop` + muted audio hold), reverse.
- Color: bundled or project `.cube` LUTs with intensity blend, exposure, contrast, saturation, temperature, tint, sharpen, presets (`natural`, `punchy`, `warm_film`, `cool_clean`, `bw_contrast`). Brand LUT default.
- Overlays: images, alpha video (ProRes 4444 / VP9 alpha via libvpx / PNG sequences), B-roll full-frame (cover/contain/stretch) or PiP with rounded corners (alpha mask), border and soft shadow (generated PNGs), rotation, opacity, z-order, position presets inside the safe zone, enter/exit animations (fade, slide_*, pop, scale_in), Ken Burns on stills/B-roll, progress bar in the brand accent. ASS hook for M4.
- Brand file loader (`cutline-core::brand`): colors drive pad, accent and SFX aliases.
- Identical segments (same cache key) render once.

Acceptance (`crates/cutline-render/tests/m3_motion.rs` + core tests):
- Exact timeline duration with 59 chained transitions (frame count of the rendered file).
- Punch-in smoothness on a high-contrast grid: scale tracks the ease curve within 1.5 %, monotone, no jitter spikes.
- Alpha compositing within ±3/255 for ProRes 4444, VP9 alpha and PNG sequence.
- Anchored layers follow ripple edits (`anchored_layer_follows_ripple`).
- Golden midpoint frame for every transition (SSIM ≥ 0.97, half-resolution luma; bless with `CUTLINE_BLESS=1`), per ffmpeg major version.

## M4 — Text & graphics
Built:
- `cutline-text`: font DB (family names as libass sees them, OS/2 metrics), libass-consistent measurement, greedy wrap + 2-line balancing, auto-fit (shrink until the block fits the box and line limit), ASS document writer (BT.709 YCbCr matrix, `PlayRes` = target size so draft renders scale), escaping (braces, backslashes, newlines), colors.
- Templates: `hook_title` (pop-in, stroke, shadow, emphasis words in accent; fitted at 110 % so the pop peak stays inside the safe zone), `lower_third` (sliding accent bar + name/subtitle), `callout` (pill + arrow up/down/left/right), `step_counter`, `big_number` (count-up), `quote`, `cta_subscribe`, `end_card` (end-screen placeholders on 16:9, CTA on Shorts), `emoji_pop` (Noto PNG overlay with pop).
- Brand file drives fonts and colors. Safe-zone positioning and clamping. `preview --safe-zones`. `templates list` (templates, transitions, effects, easings, animations, caption styles, voice chains, color presets, LUTs, emoji, fonts).
- Fontconfig isolation for libass; text boxes feed the QA safe-zone and hook checks.

Acceptance (`crates/cutline-render/tests/m4_text.rs` + unit tests):
- Golden images per template on Shorts and 16:9 (per ffmpeg major version).
- Auto-fit: a very long title renders inside the safe zone (rendered-pixel bbox), and the predicted width matches the rendered width within 8 %.
- ASS escaping unit tests, plus escaped braces in a real render.
- Byte-identical frames with system fonts and with an empty fontconfig.

## M5 — Transcription, captions, edit assist

- `cutline-transcribe`: internal transcript format, tolerant ElevenLabs Scribe importer (field variants, nested arrays, spacing/audio_event skipping), whisper.cpp sidecar (discovery, 16 kHz extraction, full-JSON parsing, DTW presets), global transcript cache, corrections (multi-word, keeps punctuation), WER, TTS helper (say / SAPI / espeak-ng), source→timeline word mapping (trims, speed, ramps, freezes, transitions, reverse, mute/replace, VO layers), speech spans.
- Captions (`cutline-text::captions`): chunking, cut snapping, styles `bold_pop`, `karaoke` (\kf), `word_by_word`, `clean_sentence` (soft box), `boxed`. Emphasis words in accent, emoji for chosen words (Noto overlays), auto-fit in the safe zone, SRT output (always written next to renders). Captions use the brand dictionary + `corrections`.
- Transcripts drive ducking (speech spans) when available.
- Auto directives: `jump_cuts`, `remove_fillers`, `punch_ins`, `sfx_on_transitions` expand to explicit items shown by `cutline expand`.
- CLI `transcribe <file> [--model|--fast] [--lang] [--import-scribe f.json] [-o out.json]`.
- Selftest Shorts project now has `bold_pop` captions from a fixture transcript.

Acceptance:
- Word mapping unit tests: trims, speed, jump-cut pieces, transitions, freeze, reverse, layers (`crates/cutline-transcribe/tests/mapping.rs`).
- WER ≤ 15 % and timing monotonicity/coverage on synthesized speech (`crates/cutline-transcribe/tests/speech.rs`): **skipped here** (no whisper-cli or TTS in this container); runs on macOS CI.
- Golden images for every caption style (+ safe-zone check), per ffmpeg major version.
- Jump cuts at the expected points (±1 frame) on a synthetic file with known gaps, with no silence > `min_silence` in the rendered output.
- Filler removal on a fixture transcript (cuts land between neighbours; SRT drops the fillers).
- Scribe import: hand-made fixture in the documented shape plus a variant-tolerance test.

## M6 — Auto-reframe
Built:
- `cutline-reframe`: `Detector` trait + `FnDetector` mock + injectable factory; YuNet 2023mar on ONNX Runtime (`onnx` feature: letterboxed BGR input, anchor-free decode, NMS); analysis by ffmpeg raw-video pipe at 6 fps / 640 px; `scdet` scene cuts; tracks, subject selection (`most_persistent`, `largest`, `left`, `right`, `index`); smoothing with dead zone, critically damped spring, max pan speed, hold + drift-to-center, scene-cut reset; bias (default keeps the face at 38 % height); per-frame crop path → `sendcmd`; manual keyframes (x, y, zoom with eased interpolation); split layout (explicit regions or the two most persistent faces).
- Render integration: cached analysis (`.cutline/cache/reframe`), geometry override per clip, `fit_blur` fallback (configurable via `reframe.fallback`) with a `W_REFRAME_NO_FACES` warning in the render report. Crop paths are kept for the review pack (M7).
- `doctor` reports detector status; `deps install face-model` (OpenCV Zoo, sha recorded).

Acceptance (`crates/cutline-render/tests/m6_reframe.rs`, `crates/cutline-reframe`):
- Panned public-domain face fixture with the real YuNet detector: tracking error ≤ 8 % of width after 1 s, ≤ 2 direction changes/s, pan speed ≤ max; the face sits near the center of the rendered 9:16 frames. The same checks also pass with an injected mock detector (default build).
- Mock-detector unit tests: dead zone, hold + drift-to-center, scene-cut reset, max speed, track selection.
- `fit_blur` fallback with a warning when no faces are found.

## M7 — QA, review pack, selftest
Built:
- All §7.2 checks run automatically after `render` (exit 1 on errors unless `--allow-qa-errors`), plus standalone `cutline qa <video> --target … [--project p]`.
- `cutline review <project> [--out review/]`: `contact_sheet.jpg` (≤ 24 stamped tiles), `cuts/*.jpg` (before|after pairs, ≤ 8), `captions/*.jpg` (safe-zone overlay + caption box, ≤ 4), `reframe/*.jpg` (source frames with crop rectangles, ≤ 4), `audio.png`, `timeline.txt`, `qa.json`, `summary.md` (QA + suggestions: static stretches > 5 s, cps, safe zone, hook, black/freeze/silence, music vs voice ≤ −18 LU, progress bar on Shorts), `preview_540p.mp4`. Images are ≤ 1568 px, ≤ 20 in total.
- `selftest --full` adds: every transition (frame count + goldens), every caption style and text template (goldens + safe zones), whisper WER (skips without whisper/TTS), reframe tracking (real detector; skips when not compiled), alpha correctness, loudness accuracy (±0.5 LU), A/V sync (beep+flash ≤ 1 frame), punch-in smoothness, and a performance benchmark (cold vs caption-only warm). Writes `selftest_report.json`.

Acceptance:
- Fault injection (`crates/cutline-qa/tests/m7_qa.rs`): wrong fps → geometry_fps error; loud audio → loudness error; 2 s black gap → black_frames (and none when intended); missing faststart → container error; captions outside the safe zone / too fast → warnings; missing hook → warning.
- Review-pack size limits and image budget (same file).
- `selftest --full`: here 12 pass, 1 skipped (whisper WER: no whisper-cli/TTS), with the onnx feature + model (reframe passes). Without `--features onnx`, reframe is skipped too. **macOS run: not done here**; CI runs `selftest --quick`.
- Performance here (4-core x86 container, ffmpeg 6.1): the 5.75 s Shorts selftest project renders in ~28 s cold and ~12 s warm (caption-only change). Far from the Apple Silicon target; recorded in the report rather than tuned.

## Blockers
- Building whisper.cpp from source was not permitted in this container, so real-speech transcription is untested here (see decisions); macOS CI covers it.
- github.com release downloads are blocked from this container (BtbN Windows builds). The code path exists; Windows CI exercises it.

## Known issues
- Speed-ramp audio uses the average tempo (see decisions).
- Transition goldens are per ffmpeg major version (xfade timing differs between 6.x and 9.x).
