Video Studio turns a written description of a video into finished, platform-ready videos. You write the video as a Markdown **spec**, improve it with Claude, attach your footage, pick a brand and the platforms you want, and press **Run**. Claude Code then plans the edit, generates the voice-over and music, records apps if the spec asks for it, and has cutline render and check every output.

This guide covers the macOS app. [Download it](/download/) if you haven't yet.

## How it works

<Steps>
  <Step title="Describe">
    Write the video as a spec: scenes, voice-over, shots, music and a call to action. See [Writing the spec](/write/spec/).
  </Step>
  <Step title="Refine">
    Ask Claude to improve the spec. You accept or reject every change. See [Working with Claude](/write/claude/).
  </Step>
  <Step title="Attach and configure">
    Drop in your media, choose a [brand preset](/configure/brand-presets/) and the [outputs](/configure/outputs/) you want.
  </Step>
  <Step title="Validate and run">
    [Validate](/run/validation/) to catch problems for free, then [run](/run/running/). A cheap dry run checks the plan before the production run makes the videos.
  </Step>
  <Step title="Review">
    Watch each output with its QA verdict, then [revise](/run/results/) with feedback if needed.
  </Step>
</Steps>
